# roccosicilia.com
Questa repo è utilizzata per la pubblicazione dei contneuti del mio blog e gli strumenti di integrazione ed update che ho iniziato a sviluppare a fine 2026 per tenere aggiornare le pagine del sito.

# struttura
Il sito è strutturato in modo da rendere immediatamente accessibili i post che pubblico regolarmente (questo progetto blog è iniziato nel 2019). Sono inoltre disponibili diverse pagine di approfondimenti e dati di sintesi di alcuni progetti che porto avanti nel campo infosec.
